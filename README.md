# Todo List dinámica

Aplicación web para gestionar tareas de forma dinámica utilizando HTML, CSS y JavaScript Vanilla.

## Funcionalidades

La aplicación permite:

- Añadir nuevas tareas.
- Añadir tareas pulsando el botón "Añadir tarea".
- Añadir tareas pulsando la tecla Enter.
- Marcar tareas como completadas.
- Mostrar visualmente las tareas completadas.
- Eliminar tareas individualmente.
- Eliminar todas las tareas completadas.
- Eliminar todas las tareas.
- Filtrar tareas por:
  - Todas
  - Pendientes
  - Completadas
- Mostrar el número total de tareas.
- Mostrar el número de tareas pendientes.
- Mostrar el número de tareas completadas.
- Guardar las tareas en localStorage para conservarlas al recargar la página.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
- DOM
- Web Storage API - localStorage
